# F2 Kalkulator Neumorphism

Kalkulator web modern dengan desain **Neumorphism** yang elegan, responsif untuk layar HP & Desktop, serta dilengkapi dengan dua tema warna (*Ungu Light* & *Coklat Dark*).

🔗 **Live Demo**: [https://f2studio.github.io/f2kalkulator/](https://f2studio.github.io/f2kalkulator/)

---

## ✨ Fitur Utama
- 💜 **Tema Ungu Light**: Tampilan *soft lilac/lavender* dengan bayangan timbul lembut.
- 🍫 **Tema Coklat Dark**: Tampilan *rich espresso/warm chocolate* dengan aksen karamel.
- 📱 **Mobile Optimized**: Mendukung layar sentuh, ukuran dinamis (*100dvh*), dan adaptasi warna status bar HP.
- ⌨️ **Dukungan Keyboard Fisik**: Ketik langsung dari numpad/keyboard PC.
- ➗ **Layar Dua Baris**: Menampilkan rumus operasi di atas dan angka hasil utama di bawah.
